Política de privacidade

Última atualização: outubro de 2026.

Sobre o aplicativo

Este aplicativo OAuth é de uso estritamente pessoal. Ele permite que o rclone, executado no computador do próprio criador, acesse a conta Google Drive dele mesmo.

Dados acessados

O aplicativo acessa arquivos e metadados do Google Drive apenas da conta que autorizou o acesso, com o único objetivo de sincronizar e montar esses arquivos localmente.

Armazenamento

Nenhum dado é enviado a servidores de terceiros. O token de acesso fica salvo apenas localmente, no arquivo de configuração do rclone, no computador do usuário.

Compartilhamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros. O uso das informações obtidas pelas APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Revogação de acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
